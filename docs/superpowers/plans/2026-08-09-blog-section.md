# Blog Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/blog` section to the Picsel site, plus its first post, arguing that most trades websites are priced for the agency rather than the trade.

**Architecture:** A new `tools/pages/blog.js` mirrors the existing `tools/pages/guides.js`: a `POSTS` data array, a `renderPost` function producing one page object per post, and an index page object. Both are registered in the `PAGES` list in `tools/build.js`, which puts them in `sitemap.xml` and `llms.txt` automatically. `guides.css` is renamed `article.css` and serves both sections.

**Tech Stack:** Plain ES modules, no framework. Static HTML generated by `node tools/build.js`. No test runner: the build itself is the test harness, and it refuses to write anything if any check fails.

## Global Constraints

Copied from the spec and from `CLAUDE.md`. Every task's requirements include these.

- **No em dashes** in any rendered copy, page title or meta description. This covers the character and the `&mdash;` entity. Check the rendered HTML, not the source.
- **Title 60 characters maximum**, enforced by the build. Must be unique across all pages.
- **Meta description 155 characters maximum**, enforced by the build. Must be unique across all pages.
- **Exactly one `<h1>` per page**, enforced by the build.
- **Never write the words "Hayle" or "Cornwall" into blog copy.** `findLocationClaims` in `tools/build.js` errors on them unless the string came from `projects.js`. A client's own name ("Lanora House") is stripped before the check and is safe; a bare town name is not. The post refers to the client by name and never names the town.
- **Never write "per patch" without the word "Growth" on the same page.** `findLooseExclusivityClaim` errors on it.
- **No phone number or email address in copy.** They come from `site.config.js` only.
- **Prices come from `pricing.js`**, never typed as literals, so the post cannot drift out of agreement with `/prices`.
- **The post may not make any search or ranking claim.** Search Console has no data for the client before 12 June 2026 and average position is 27.5. Decided and settled; do not reintroduce.
- **The post may not present the review result as an outcome of the build**, and may not put a quote in a client's mouth. Figures are reported as facts.

**Verified figures, checked 9 August 2026.** Lanora House Google reviews went from 18 to 36 over two months and stand at 38 today at a 5.0 average. These are the only client numbers the post may state.

```js
/* ---- The blog -------------------------------------------------------------
   Guides carry FAQPage, because a guide is a question and its answer and that
   is the shape an assistant wants. A post is not that. It is dated, it has an
   argument, and the useful thing to declare about it is when it was written and
   who by.

   Author and publisher are both the Organization rather than a Person node.
   Inventing a Person means inventing the fields that make one worth having, and
   the studio is one man whose name is already on the Organization. */
export function blogPosting({ headline, description, path, datePublished }) {
  return {
    '@type': 'BlogPosting',
    '@id': `${absoluteUrl(path)}#post`,
    headline,
    description,
    datePublished,
    url: absoluteUrl(path),
    mainEntityOfPage: absoluteUrl(path),
    author: { '@id': ORG_ID },
    publisher: { '@id': ORG_ID },
    isPartOf: { '@id': `${absoluteUrl('/blog/')}#blog` },
  };
}

/* The Blog itself, on the index. Each post is referenced by @id rather than
   restated, so a crawler reading both pages sees one post described once. */
export function blogNode(posts) {
  return {
    '@type': 'Blog',
    '@id': `${absoluteUrl('/blog/')}#blog`,
    name: `${SITE.name} blog`,
    url: absoluteUrl('/blog/'),
    publisher: { '@id': ORG_ID },
    blogPost: posts.map((post) => ({
      '@type': 'BlogPosting',
      '@id': `${absoluteUrl(post.path)}#post`,
      headline: post.headline,
      url: absoluteUrl(post.path),
    })),
  };
}
```

- [ ] **Step 2: Append the post renderer to the same file**

```js
function renderPost(post) {
  const sections = post.sections
    .map(
      (section) => `        <section class="post__section">
          <h2>${escapeHtml(section.h2)}</h2>
${(section.paragraphs || [])
  .map((text) => `          <p>${text}</p>`)
  .join('\n')}${
        section.list
          ? `\n          <ul class="post__list">
${section.list.map((item) => `            <li>${escapeHtml(item)}</li>`).join('\n')}
          </ul>`
          : ''
      }
        </section>`,
    )
    .join('\n\n');

  const content = `    <article class="section post">
      <div class="wrap post__inner">
        <p class="eyebrow"><a class="post__back" href="/blog/">Blog</a></p>
        <h1 class="post__headline">${escapeHtml(post.headline)}</h1>
        <p class="post__meta">
          <time datetime="${escapeHtml(post.date)}">${escapeHtml(longDate(post.date))}</time>
        </p>

        <p class="post__standfirst">${escapeHtml(post.standfirst)}</p>

${sections}

        <aside class="post__close">
          <p>${escapeHtml(post.close.line)}</p>
          <a class="post__close-link" href="${escapeHtml(post.close.href)}">${escapeHtml(post.close.cta)}</a>
        </aside>
      </div>
    </article>`;

  return {
    path: `/blog/${post.slug}/`,
    title: post.title,
    description: post.description,
    styles: ['/article.css'],
    schemaExtra: [
      blogPosting({
        headline: post.headline,
        description: post.description,
        path: `/blog/${post.slug}/`,
        datePublished: post.date,
      }),
      breadcrumbs([
        { name: 'Home', path: '/' },
        { name: 'Blog', path: '/blog/' },
        { name: post.headline, path: `/blog/${post.slug}/` },
      ]),
    ],
    content: [
      content,
      renderContactBand({
        heading: 'Want a straight price?',
        body: 'Ring and describe the job. We&rsquo;ll tell you what&rsquo;s involved and what it would cost, in plain English, with no obligation.',
      }),
    ].join('\n\n'),
  };
}

export const BLOG_PAGES = POSTS.map(renderPost);
```

Note: paragraphs are inserted without escaping because one of them carries an
anchor tag. Everything in `POSTS` is written by hand in this file and never
comes from user input, so this is safe here. Headlines, dates and list items are
still escaped.
